# 健人｜哲愷訓練日誌

個人化重訓及跑步日誌，採用純前端 HTML/CSS/JavaScript。正式網址（需先開啟 GitHub Pages）：https://easylearnfromtw.github.io/Builder/

## GitHub Pages

在儲存庫 **Settings → Pages → Build and deployment** 選 **Deploy from a branch**，選 `main` / `/(root)` 並儲存。部署完成後由上面網址開啟，請勿用 `/index.html` 以外的其他任意路徑。

## 第一次使用與本機資料

首次開啟且瀏覽器沒有儲存紀錄時，重訓次數、跑步里程、運動時間、體適能分數及圖表都從 **0** 開始，不會產生範例訓練。預設的運動菜單與每週目標只是操作模板，**不是既有訓練成績**。

若這個瀏覽器已存有真實紀錄，網站會自動讀取既有的 `kai-log-v1` 本機資料；舊版自動建立且標記 `ex: true` 的範例會移除，但不會刪除真實紀錄。跨裝置不會自動帶入資料，須由設定頁的備份匯入或 Strava 同步。

## 快速加入過去重訓與 iOS 操作

- **重訓 → 快速加入過去重訓**：顯示本機真實紀錄中最近 4 種不同的重訓（依名稱與動作順序去重）。新用戶沒有紀錄時保持空白，不產生假資料。
- **帶入編輯**：將當次動作、重量、次數、RPE、熱身組複製成今天的草稿，所有完成勾選維持未完成；完成訓練後才真正存成新紀錄。
- **快速記錄**：開啟日期與時間確認頁；只有點擊「確認加入紀錄」才會新增另一筆紀錄。請僅用於實際完成與上次相同內容的訓練。
- **訓練中 → 沿用上次組數**：單一動作也能一鍵帶入上次的重量、次數與組數；若本次已填寫過資料，需再按一次確認覆寫。
- **iOS Safari**：改善表單聚焦引發的自動放大、取消鍵盤出現時的強制置中平滑捲動；觸控裝置底部導覽不再隨滑動縮放。**未關閉使用者自行雙指縮放**。

## Strava 串聯

在網站右上角 **設定與備份 → 串聯 Strava → 第一次使用？展開 Strava 串聯教學** 有完整操作流程。

GitHub Pages 是公開靜態網站，無法安全保管 Strava Client Secret，因此須另外部署專案的 `strava-worker/` 至 Cloudflare Worker。請依 [Strava 後端部署說明](strava-worker/README.md) 設定 API App、Worker KV、機密環境變數。建立後，在健人設定頁填入 Worker 網址，再進行官方 OAuth 授權及活動同步。**在 Worker 尚未部署之前，不會自動完成 Strava 串聯。**

訓練資料存在目前瀏覽器的 localStorage；請定期在設定中備份。
